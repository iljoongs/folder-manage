# 03. 폴더 이름 생성 규칙

## 입력 항목

| 항목 | 설명 | 예시 |
|---|---|---|
| 상위 폴더 | 폴더들이 생성될 부모 디렉터리 | `D:\Photos\Trip` |
| 접두사 (선택) | 숫자 앞에 붙는 고정 텍스트 | `Chapter `, `IMG_` |
| 접미사 (선택) | 숫자 뒤에 붙는 고정 텍스트 | ` 화`, `_raw` |
| 시작 번호 | 시퀀스 시작 값 | `1` |
| 종료 번호 | 시퀀스 상한 값 (이 값을 넘지 않음) | `10` |
| 증가 단위 | 각 단계마다 더할 값 (기본 1) | `2` |
| 자리수 | 숫자의 최소 자릿수 (0 패딩 기준) | `2` |

## 폴더 이름 조합

```
폴더 이름 = 접두사 + 0으로 패딩된 숫자 + 접미사
```

- 접두사/접미사가 비어 있으면 숫자만으로 폴더 이름을 만든다.

## 자리수(패딩) 규칙

- 자리수는 **최소 자릿수**다. 숫자의 실제 자릿수가 지정한 자리수보다 크면 잘라내지 않고 그대로 표시한다.
- 예 (자리수 = 2): `1 → 01`, `9 → 09`, `10 → 10`, `100 → 100`, `999 → 999`.

## 증가 단위(step) 규칙

- 시작 번호부터 `+step`씩 증가하며, 값이 **종료 번호를 넘어서면 그 값은 생성하지 않고 멈춘다**(종료 번호에 정확히 맞아떨어지지 않아도 됨).
- 예: 시작 1, 종료 10, 증가 2 → `1, 3, 5, 7, 9` (11은 10을 넘으므로 생성 안 함).
- 예: 시작 1, 종료 5, 증가 1 → `1, 2, 3, 4, 5`.

## 유효성 검사 (v1 기준안 — 확정 필요, [doc/05-open-decisions.md](05-open-decisions.md) 참고)

- 시작 번호 > 종료 번호 → 오류로 처리하고 미리보기를 만들지 않는다.
- 증가 단위 ≤ 0 → 오류.
- 자리수 < 1 → 오류(또는 기본값 1로 취급 — 확정 필요).
- 시작/종료/증가/자리수가 숫자가 아니거나 비어 있음 → 오류.
- 상위 폴더가 선택되지 않음 → 오류.

## 미리보기 및 생성 동작

- 미리보기는 위 규칙으로 계산된 전체 폴더 이름 목록을 순서대로 보여주며, 상위 폴더에 이미 같은 이름이 있는 항목은 "이미 존재" 상태로 표시한다.
- "폴더 생성" 실행 시, "이미 존재"로 표시된 항목은 건너뛰고 나머지만 실제로 생성한다.
- 생성 완료 후 생성된 개수 / 건너뛴 개수를 사용자에게 알려준다.
