# 03. 폴더 이름 생성 규칙

> 이 문서는 **탭 1(폴더 만들기)** 기능의 규칙이다. 탭 구조는 [06-main-window-tabs.md](06-main-window-tabs.md) 참고.

## 입력 항목

| 항목 | 설명 | 예시 |
|---|---|---|
| 상위 폴더 | 폴더들이 생성될 부모 디렉터리 | `D:\Photos\Trip` |
| 접두사 (선택) | 숫자 앞에 붙는 고정 텍스트 | `Chapter `, `IMG_` |
| 접미사 (선택) | 숫자 뒤에 붙는 고정 텍스트 | `화`, `_raw` |
| 시작 번호 | 시퀀스 시작 값 | `1` |
| 종료 번호 | 시퀀스 상한 값 (이 값을 넘지 않음) | `10` |
| 증가 단위 | 각 단계마다 더할 값 (기본 1) | `2` |
| 자리수 | 숫자의 최소 자릿수 (0 패딩 기준) | `2` |

### 입력 기본값

| 항목 | 기본값 |
|---|---|
| 접두사 | (빈 값) |
| 접미사 | `화` |
| 시작 번호 / 종료 번호 | `1` / `10` |
| 증가 단위 | `1` |
| 자리수 | `1` (즉 `1화`, `2화`처럼 0 패딩 없음) |

## 폴더 이름 조합

```
폴더 이름 = 접두사 + 0으로 패딩된 숫자 + 접미사
```

- 접두사/접미사가 비어 있으면 숫자만으로 폴더 이름을 만든다.

## 자리수(패딩) 규칙

- 자리수는 **최소 자릿수**다. 숫자의 실제 자릿수가 지정한 자리수보다 크면 잘라내지 않고 그대로 표시한다.
- 예 (자리수 = 2): `1 → 01`, `9 → 09`, `10 → 10`, `100 → 100`, `999 → 999`.

## 증가 단위(step) 규칙

- 시작 번호부터 `+step`씩 증가하며, 값이 **종료 번호를 넘어서면 그 값은 생성하지 않고 멈춘다**(종료 번호에 정확히 맞아떨어지지 않아도 됨).
- 예: 시작 1, 종료 10, 증가 2 → `1, 3, 5, 7, 9` (11은 10을 넘으므로 생성 안 함).
- 예: 시작 1, 종료 5, 증가 1 → `1, 2, 3, 4, 5`.

## 유효성 검사

- 시작 번호 > 종료 번호 → 오류로 처리하고 미리보기를 만들지 않는다.
- 증가 단위 ≤ 0 → 오류.
- 자리수 < 1 → 오류.
- 시작/종료/증가/자리수가 숫자가 아니거나 비어 있음 → 오류.
- 상위 폴더가 선택되지 않음 → 오류.
- **접두사/접미사에 Windows 폴더명으로 쓸 수 없는 문자**(`\ / : * ? " < > |`)가 포함되어 있으면 입력 자체를 오류로 거부한다(자동 제거/치환하지 않는다).

## 미리보기 및 생성 동작

- 계산된 전체 개수가 대량 생성 경고 임계치([doc/05-open-decisions.md](05-open-decisions.md) 참고, 기본 1000개)를 넘으면 **미리보기 단계에서도** 먼저 확인 팝업을 띄운다(생성 시점뿐 아니라 미리보기 계산·렌더링 시점에도 동일하게 적용).
- 미리보기는 위 규칙으로 계산된 전체 폴더 이름 목록을 순서대로 보여주며, 상위 폴더 안의 같은 이름 항목을 아래 세 가지 상태로 구분해 표시한다:
  - **신규**: 아직 없음 → 생성 대상
  - **이미 존재**: 같은 이름의 폴더가 이미 있음 → 건너뜀
  - **충돌**: 같은 이름의 **파일**이 있음(폴더가 아님) → 오류로 별도 표시, 건너뜀
- "폴더 생성" 실행 시, "이미 존재"와 "충돌" 항목은 모두 건너뛰고 "신규" 항목만 실제로 생성한다.
- 생성 완료 후 생성된 개수 / 이미 존재해서 건너뛴 개수 / 충돌로 건너뛴 개수를 구분해 사용자에게 알려준다.

## 자동 생성 (빠진 번호 채우기)

상위 폴더에 이미 있는 숫자 폴더를 보고, 중간에 빠진 번호의 폴더를 한 번에 채워 만드는 기능이다. 예: `1화`, `2화`, `20화`가 있으면 `3화` ~ `19화`를 만든다.

1. **기존 폴더 찾기**: 상위 폴더 바로 아래의 **폴더**(파일 제외)만 대상으로, 현재 입력된 접두사/접미사와 `접두사 + 숫자 + 접미사` 형식이 정확히 일치하는 이름에서 숫자를 뽑는다. 대소문자는 구분하지 않고, 0 패딩은 무시한다(`01화`와 `1화`는 모두 1). 접두사/접미사에 정규식 특수문자가 있어도 문자 그대로 비교한다. `int` 범위를 넘는 숫자는 무시한다.
2. **범위 결정**: 찾은 숫자 중 **가장 작은 값 ~ 가장 큰 값**이 범위다(시작/종료 번호 입력란은 쓰지 않으며 값도 바꾸지 않는다).
3. **이름 생성**: 범위 안에서 현재 **증가 단위**와 **자리수**를 그대로 적용해 위 규칙대로 이름을 만든다(가장 작은 값에서 시작해 증가 단위씩 증가). 자리수는 새로 만드는 이름에만 적용되며, 기존 폴더의 패딩에서 추정하지 않는다.
4. **생성**: 미리보기를 거치지 않고 **바로** 빠진 폴더를 만든다(이미 있는 폴더는 건너뜀, 같은 이름의 파일은 "충돌"로 건너뜀). 끝나면 범위 전체를 미리보기 목록에 보여주고 `생성 N개, 이미 존재 N개, 충돌 N개`를 알려준다. 만들 폴더가 없으면 그렇게 알려준다.
5. **오류/경고**: 상위 폴더 미선택·없음, 형식에 맞는 폴더가 하나도 없음, 증가 단위/자리수/접두사·접미사 유효성 오류는 메시지로 알리고 아무것도 만들지 않는다. 범위 크기가 대량 생성 경고 임계치(1000개)를 넘으면 미리보기와 같은 확인 팝업을 먼저 띄우고, 취소하면 아무것도 만들지 않는다.
