# 07. 탭 2: 이미지 파일 변경

> **상태: 초안 (코드 없음).** 사용자가 준 개요를 문서로 옮긴 것이다. 표기: **[확정]** = 사용자가 말한 내용, **[가정]** = 개요를 해석해서 채운 부분(확인 필요), **[제안]** = 안전/일관성을 위한 제안(확정 아님). 아직 정해지지 않은 질문은 [05-open-decisions.md](05-open-decisions.md) "탭 2 미결정 항목"에 모아 두었다. 탭 구조는 [06-main-window-tabs.md](06-main-window-tabs.md) 참고.

## 목적 [확정]

어떤 폴더에는 폴더와 파일이 함께 들어 있고, 폴더와 파일은 (확장자를 뺀) 같은 이름을 갖는다. 이 "공통 이름"을 특정 이름으로 바꾸면, 같은 이름을 가진 폴더와 파일들이 모두 함께 새 이름으로 바뀌는 기능이다.

## 용어

| 용어 | 뜻 |
|---|---|
| 대상 폴더 | 작업할 폴더. 그 **바로 아래**의 폴더와 파일이 대상이다 **[가정]** (하위 폴더 안쪽까지 재귀로 보지 않음) |
| 접미사 | 이름 끝에 붙는 `.debug` 또는 `.debug-result`. 있어도 같은 이름으로 판단한다 **[확정]** |
| 공통 이름 | 폴더/파일에서 확장자와 접미사를 뺀 이름 |
| 이름 그룹 | 공통 이름이 같은 폴더와 파일들의 묶음. 폴더 0~1개 + 파일 0개 이상 |
| 새 이름 | 사용자가 지정하는, 그룹이 바뀔 공통 이름 |

## 공통 이름 판단 규칙

- **파일**: 확장자를 뺀 이름에서, 끝에 `.debug` 또는 `.debug-result`가 있으면 그것도 뺀 이름이 공통 이름이다 **[확정]**. 접미사는 확장자 앞에 온다 **[가정]** (`001.debug.png`).
- **폴더**: 폴더에는 확장자 개념이 없으므로 이름이 곧 공통 이름이다. 폴더 이름 끝에 `.debug`/`.debug-result`가 붙는 경우도 파일과 같은 규칙으로 접미사를 뗀다 **[가정]**. (`v1.2`처럼 점이 들어간 폴더 이름을 확장자로 오인하지 않는다.)
- 파일의 확장자는 **마지막 점 뒤**만이다(`001.v2.png`의 확장자는 `.png`, 공통 이름은 `001.v2`) **[가정]**.
- 접미사 목록(`.debug`, `.debug-result`)은 코드에 박아 넣지 않고 바꿀 수 있는 목록으로 둔다 **[제안]**.
- 이름 비교는 대소문자를 구분하지 않는다(Windows 파일 시스템과 동일) **[제안]**.

예 (대상 폴더 안):

| 항목 | 종류 | 공통 이름 |
|---|---|---|
| `001` | 폴더 | `001` |
| `001.png` | 파일 | `001` |
| `001.debug.png` | 파일 | `001` |
| `001.debug-result.png` | 파일 | `001` |
| `002` / `002.png` | 폴더 / 파일 | `002` (위와 다른 그룹) |

## 이름 변경 동작

공통 이름을 새 이름으로 바꾸면 그룹의 **모든 폴더·파일이 함께** 바뀐다 **[확정]**. 각 항목의 접미사와 확장자는 그대로 유지하고 공통 이름 부분만 바뀐다 **[가정]**.

예: 그룹 `001`의 새 이름을 `ch01`로 지정

| 변경 전 | 변경 후 |
|---|---|
| `001` (폴더) | `ch01` |
| `001.png` | `ch01.png` |
| `001.debug.png` | `ch01.debug.png` |
| `001.debug-result.png` | `ch01.debug-result.png` |

## 안전 규칙 (제안 — 확정 아님)

파일 이름을 바꾸는 기능은 탭 1(폴더 생성)과 달리 기존 항목을 건드리므로 더 조심스러운 규칙을 제안한다.

1. **미리보기 먼저**: 변경 전 → 변경 후 목록을 보여준 뒤 실행한다(탭 1과 같은 흐름).
2. **충돌 검사는 "바뀐 뒤의 최종 이름" 기준**: 새 이름과 같은 이름의 다른 항목이 이미 있으면 그 그룹은 충돌로 표시하고 건너뛴다. 다른 그룹이 같은 작업에서 이름이 바뀌어 비게 되는 이름은 충돌이 아니다.
3. **그룹 단위로 전부 성공 또는 전부 취소**: 그룹 안 항목을 바꾸다 하나가 실패하면(파일이 사용 중 등) 이미 바꾼 항목을 원래대로 되돌려, 폴더와 파일 이름이 어긋난 상태를 남기지 않는다.
4. **이름 검증**: 새 이름에 Windows 이름으로 쓸 수 없는 문자(`\ / : * ? " < > |`)가 있으면 거부한다(탭 1의 접두사/접미사 규칙과 동일). 빈 이름, 끝이 `.`/공백인 이름, 예약 이름(`CON`, `NUL` 등)도 거부한다.
5. **대소문자만 바꾸는 경우**(`abc` → `ABC`): 같은 이름으로 오인해 충돌 처리하지 않고 임시 이름을 거쳐 바꾼다.
6. **결과 요약**: 바뀐 그룹/항목 수, 건너뛴 수(충돌), 실패 수를 구분해 알린다.
7. 여러 그룹을 한 번에 바꾸는 경우 이름이 서로 맞바뀌거나 밀리는 상황(`1→2`, `2→3`)이 생길 수 있으므로 임시 이름을 거치는 2단계로 바꾼다.

## 입력과 화면 (미정)

- 대상 폴더 선택, 그룹 목록 표시, 새 이름 입력, 미리보기 → 실행의 흐름은 탭 1과 비슷하게 가는 것이 자연스럽다 **[제안]**.
- **새 이름을 어떻게 지정하는지**(그룹 하나를 골라 새 이름 입력 / 여러 그룹에 번호 규칙을 일괄 적용 등)와 화면 배치는 아직 정해지지 않았다 → [05-open-decisions.md](05-open-decisions.md).

## 범위 (제안)

- 대상 폴더 바로 아래 항목만 다룬다(재귀 X).
- 이름만 바꾼다. 파일 내용, 폴더 위치(이동), 확장자는 바꾸지 않는다.
- 이미지 파일만 대상으로 제한할지(확장자 필터)는 미정이다 → [05-open-decisions.md](05-open-decisions.md).
