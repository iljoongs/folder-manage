# 04. UI 구성 및 흐름

## 화면 구성 (단일 창, v1)

1. **상위 폴더 선택**: 경로 텍스트박스 + "찾아보기" 버튼(폴더 선택 다이얼로그).
2. **이름 규칙 입력**:
   - 접두사 입력란 (선택)
   - 접미사 입력란 (선택)
   - 시작 번호, 종료 번호, 증가 단위, 자리수 입력란
3. **미리보기 목록**: "미리보기" 버튼을 누르면 [doc/03-folder-naming-spec.md](03-folder-naming-spec.md) 규칙대로 계산한 폴더 이름들을 목록으로 표시. 각 항목에 상태(신규 / 이미 존재 / 충돌(파일 있음)) 표시.
4. **생성 실행**: "폴더 생성" 버튼 → "신규" 항목만 실제로 생성 → 완료 후 결과 요약(생성 N개, 이미 존재라 건너뜀 N개, 충돌로 건너뜀 N개) 표시.

## 흐름

```
상위 폴더 선택
   ↓
이름 규칙 입력 (접두사/접미사/시작/종료/증가/자리수)
   ↓
[미리보기] → 유효성 검사 실패 시 오류 메시지
           → 전체 개수가 임계치 초과 시 확인 팝업(진행/취소)
           → 성공 시 목록 표시 (신규/이미 존재/충돌 구분)
   ↓
[폴더 생성] → 신규 항목만 생성, 이미 존재·충돌 항목은 건너뜀
   ↓
결과 요약 표시 (생성/이미 존재/충돌 개수 구분)
```

## 입력값 변경 시 미리보기 처리 (확정 필요)

입력값(접두사/시작/종료 등)을 바꾼 뒤 다시 "미리보기"를 눌러야 갱신되는지, 아니면 입력이 바뀔 때마다 자동으로 갱신할지는 아직 정하지 않았다 → [doc/05-open-decisions.md](05-open-decisions.md).
