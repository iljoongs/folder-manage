# 04. UI 구성 및 흐름

> 이 문서는 **탭 1(폴더 만들기)** 안의 화면 구성과 흐름이다. 메인 윈도우는 탭 구조이고 아래 내용은 탭 1(`MakeFolderTabView`)의 내용 영역이다 → [06-main-window-tabs.md](06-main-window-tabs.md). 탭 2의 화면은 [07-image-rename-spec.md](07-image-rename-spec.md) "입력과 화면".

## 화면 구성 (탭 1, v1)

1. **상위 폴더 선택**: 경로 텍스트박스(직접 입력·붙여넣기도 가능) + "찾아보기" 버튼(폴더 선택 다이얼로그).
2. **이름 규칙 입력**:
   - 접두사 입력란 (선택)
   - 접미사 입력란 (선택, 기본값 `화`)
   - 시작 번호, 종료 번호, 증가 단위, 자리수 입력란 (기본값은 [doc/03-folder-naming-spec.md](03-folder-naming-spec.md) "입력 기본값" 참고)
3. **미리보기 목록**: "미리보기" 버튼을 누르면 [doc/03-folder-naming-spec.md](03-folder-naming-spec.md) 규칙대로 계산한 폴더 이름들을 목록으로 표시. 목록은 "폴더 이름 / 상태" 두 열이고, 상태는 신규 / 이미 존재 / 충돌(파일 있음) 중 하나다. 열 머리글을 눌러 정렬할 수 있고(첫 클릭 오름차순, 다시 클릭하면 내림차순) 숫자는 숫자 크기로 정렬한다(`1화, 2화, … 10화`, 문자열 순서가 아니다 → `Common/NaturalSortBehavior`).
4. **생성 실행**: "폴더 생성" 버튼(목록에 "신규" 항목이 있을 때만 활성화) → "신규" 항목만 실제로 생성 → 완료 후 결과 요약(생성 N개, 이미 존재라 건너뜀 N개, 충돌로 건너뜀 N개) 표시.
5. **자동 생성**: "자동 생성" 버튼(버튼 순서: 자동 생성 · 미리보기 · 폴더 생성) → 상위 폴더의 기존 숫자 폴더(예: `1화`, `2화`, `20화`)를 보고 빠진 번호(`3화` ~ `19화`)를 미리보기 없이 바로 생성 → 범위 전체를 목록에 보여주고 결과 요약 표시. 규칙 상세는 [doc/03-folder-naming-spec.md](03-folder-naming-spec.md) "자동 생성" 참고. 마우스를 올리면 동작 설명 툴팁이 뜬다.
6. **상태 메시지**: 창 아래쪽 한 줄 영역에 유효성 오류, 미리보기 요약(전체/신규/이미 존재/충돌 개수), 생성 결과를 보여준다.

## 접미사 입력란 동작

접미사 기본값(`화`)이 손대지 않은 채 남아 있는 상태에서 사용자가 입력을 시도하면(클릭 또는 Tab으로 진입 후 타이핑) 기본값이 자동으로 지워지고 입력한 내용이 그 자리를 대신한다. 구현은 입력란에 처음 포커스가 올 때 기본값을 전체 선택해 두는 방식이라 IME(한글) 입력에서도 동일하게 동작한다. 한 번이라도 다른 값으로 바뀌면(기본값이 아닌 텍스트가 되면) 이후에는 일반 입력란처럼 동작하며 기본값을 다시 자동 삭제하지 않는다. 아무것도 입력하지 않고 나가면 `화`가 그대로 유지된다.

## 흐름

```
상위 폴더 선택
   ↓
이름 규칙 입력 (접두사/접미사/시작/종료/증가/자리수)
   ↓
[미리보기] → 유효성 검사 실패 시 오류 메시지
           → 전체 개수가 임계치 초과 시 확인 팝업(진행/취소)
           → 성공 시 목록 표시 (신규/이미 존재/충돌 구분)
   ↓
[폴더 생성] → 신규 항목만 생성, 이미 존재·충돌 항목은 건너뜀
   ↓
결과 요약 표시 (생성/이미 존재/충돌 개수 구분)
```

## 입력값 변경 시 미리보기 처리

입력값(접두사/시작/종료 등)을 바꿔도 목록은 자동으로 갱신되지 않는다. "미리보기" 버튼을 다시 눌러야 갱신된다 → [doc/05-open-decisions.md](05-open-decisions.md).
