# 01. 개요 및 범위

## 앱 개요

여러 기능을 **탭**으로 나눠 제공하는 WPF 데스크톱 앱이다. 메인 윈도우는 탭 구조이고, 탭은 기능 단위로 나눈다. 탭 구성과 공통 규칙은 [06-main-window-tabs.md](06-main-window-tabs.md), 아직 정해지지 않은 사항은 [05-open-decisions.md](05-open-decisions.md)를 본다.

- **탭 1: 폴더 만들기** — 지금까지 만든 make-folder 기능. 아래 "탭 1"에서 설명한다.
- **탭 2: 이미지 파일 변경** — 한 폴더 안에서 공통 이름(확장자와 `.debug`/`.debug-result` 접미사를 뺀 이름)이 같은 폴더·파일들의 이름을 함께 바꾼다. 상세는 [07-image-rename-spec.md](07-image-rename-spec.md).
- **탭 3 이후**: 있다면 사용자가 기능을 설명해 줄 예정이다. 설명을 받은 뒤 이 문서와 [06-main-window-tabs.md](06-main-window-tabs.md)에 추가한다.

# 탭 1: 폴더 만들기

## 목적

사용자가 상위 폴더를 하나 선택하면, 그 안에 연속된 번호를 가진 폴더 여러 개를 한 번에 만들어주는 기능이다. 예를 들어 사진/영상 회차 폴더, 챕터 폴더처럼 "01, 02, 03 ... " 형태로 반복되는 폴더를 매번 손으로 만드는 번거로움을 없애는 것이 목표다.

## 핵심 흐름

1. 사용자가 상위(부모) 폴더를 선택한다.
2. 시작 번호 / 종료 번호 / 증가 단위 / 자리수 / (선택) 접두사·접미사를 입력한다.
3. 생성될 폴더 이름 목록을 미리보기로 확인한다.
4. "폴더 생성"을 누르면 실제로 폴더들이 만들어진다.

## v1(MVP) 범위

- 시퀀스는 **숫자만** 지원한다. 문자(a, b, c...)나 날짜 시퀀스는 범위 밖이며, 필요해지면 이후 버전에서 확장한다 → [doc/05-open-decisions.md](05-open-decisions.md) 참고.
- 폴더 이름은 `접두사 + 자리수 맞춘 숫자 + 접미사` 형태다. 접두사/접미사는 선택 입력(빈 값이면 숫자만 사용).
- 상위 폴더 안에 이미 같은 이름의 폴더가 있으면 **건너뛴다** (덮어쓰거나 중단하지 않음).
- 생성 전에 결과를 미리보기로 보여준다.
- **자동 생성**: 상위 폴더에 이미 있는 숫자 폴더(예: `1화`, `2화`, `20화`)의 최솟값~최댓값 사이에서 빠진 번호의 폴더(`3화` ~ `19화`)를 한 번에 채워 만든다 → [doc/03-folder-naming-spec.md](03-folder-naming-spec.md) "자동 생성".
- 접미사 기본값은 `화`, 자리수 기본값은 `1`이다.

## 범위 밖 (v1에서 하지 않는 것)

- 문자/날짜 등 숫자가 아닌 시퀀스
- 폴더 생성 결과에 대한 되돌리기(undo)/일괄 삭제 기능
- 생성 이력 저장(로그 파일 등)

이 항목들은 실제로 필요해지면 별도 논의 후 문서와 함께 추가한다.
